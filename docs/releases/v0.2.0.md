Parsing gets considerably less lossy. Basement floors, lettered units and compound village/road dictionary keys were each silently dropping part of an address while still returning a confident-looking result — a grammatically valid English address with a piece missing, which is the worst way for this library to fail. There is also a new `menpai` CLI, and `translate()` now tells you why it failed.

```sh
npm install menpai@0.2.0
```

## Before you upgrade

**`confidence` changes for some inputs that previously said `exact`.** A floor of `0` or `1200`, a house number of `0`, or a digit run long enough to overflow to `Infinity` now report `unknown`. If you route on `confidence === "exact"`, these stop passing — which is the point, but it is a change in behaviour.

**Results can carry two new optional keys.** `translate()` sets `warnings` on roughly a fifth of real inputs, and `error` when parsing fails outright. Both are omitted when empty, so this only matters against a strict schema, a fixed-column insert, or a stored snapshot.

## Parsing fixes

Each of these previously produced a plausible-looking result with part of the address thrown away.

- **Basement floors.** `地下2樓`, `地下二樓`, `地下2層`, `B2F` and `B2樓` (with an optional `之N` / `-N`) now yield `floor: "B2"` and print as `B2 F.`. A bare `B2` is read as a floor only when it ends the address or is followed by a separated room, so `B1棟5樓` and `B2號` are still reported rather than half-read — inventing a basement floor there would discard the real one.
- **Lettered units.** `A室`, `A1室`, `3樓之B` and `3F-B` now yield `room: "A"` / `floorSuffix: "B"` and print as `Rm. A` / `3 F.-B`. The form is deliberately narrow — one Latin letter plus up to two digits — so `AB室`, `會議室` and `3樓之B棟` are still reported.
- **Compound village/road keys.** The official list carries entries like `福星里福星`, and a greedy match consumed the village plus a fragment and stranded the rest: `臺北市中正區福星里福星北一街1號` lost the village, the road and the house number at once. The village is now split off only when it is a real dictionary village, the road found after it reads further, and the split does not orphan a structural marker.
- **Implausible numbers are no longer `exact`.** A floor of `0` or `B99`, a lane of `999999`, a house number of `0` — these come back `unknown`, with the value passed through so a human can see what was meant. The ceilings are deliberately generous; the point is to refuse an impossible value, not to validate addresses.

## Diagnostics

- `translate()` no longer throws away what `parse()` learned. `FormatResult` gains `error` and `warnings`. Before this it returned `english: ""` with no way to tell `city-not-found` from `area-ambiguous`, so anyone building a real UI had to bypass `translate()` entirely.
- `ParseWarning` gains `text` (the fragment the warning is about) and `resolved` (what was used instead). This is how you tell a fragment the library *guessed* at from one it *skipped* — without it, a consumer rendering both lists says "could not interpret this" directly above "romanized by rule" about the same text. Build your own copy from `code`, `text` and `resolved`; the wording of `message` is not part of the contract.
- `ParseError` gains `candidates` for `area-ambiguous`, so a caller can offer the choice instead of asking the user to work out which cities were meant. Also fixes a case where a non-matching postal code emptied the list and the message read `exists in more than one city ()`.

## CLI

```sh
npx menpai "台北市大安區忠孝東路四段1號"
cat addresses.csv | menpai --json > out.jsonl || review.sh
```

With no argument it reads stdin and translates a line at a time. Exit status carries the result — `0` every address `exact`, `1` something needs a human, `2` a usage error — so a batch script needs no output parsing. Addresses go to stdout and notes to stderr. Still zero dependencies; argv parsing is hand-rolled, and the bin is transpiled rather than bundled so the dictionaries are not shipped twice.

The whole batch is held in memory, so this suits a spreadsheet column rather than a multi-million-row export.
